# MyVoice Admin V2 (Operator Console) Implementation Plan

> **For agentic workers:** execute task-by-task; steps use checkbox (`- [ ]`) syntax.

**Goal:** Build V2 of the admin (`/admin-lab`) — all 12 sections reimagined as an operator
console — on the `admin-v2` branch, purely additive so it never disturbs V1 on `main`.

**Architecture:** New routes under `src/app/admin-lab/*` and new components under
`src/components/admin-lab/*`, reusing V1's `AdminProvider`, `adminMockData.ts`, and shared
primitives (`StatusPill`, `ConfirmDialog`, `Toast`, `Tabs`, `Field`, `DataTable`,
`PanelSwitcher`, `RichTextEditor`, `TwoPaneChat`). A small `LabUIProvider` holds V2-only UI
state (command palette open, focused member). No V1 file is modified.

**Tech Stack:** Next.js 14 static export, React 18, TS, Tailwind (existing tokens). No new deps.

## Global Constraints
- **Additive only:** never edit `src/app/admin/*`, `src/lib/adminMockData.ts`, or existing
  `AdminProvider` method signatures. New provider methods (if truly needed) are added additively.
- Static-export safe (client components; no build-vs-hydration `Date` drift).
- Base-path aware (`next/link`, `asset()`); reuse `sessionStorage['mv_admin']` + `/admin/login`.
- Signal Yellow reserved for money/approve+save; status only via `StatusPill`.
- Verify: `npx tsc --noEmit` + `npm run build`; commit per task. Dev server must be stopped
  before `npm run build`.

- Verify + commit.
